№1 Задача Расчётные задачи по C# (статические функции)
Для решения задачи нужно сделать ввод который проверяет и защищает от некорректного ввода с помощью циклов с предусловием через метод TryParse.
Мы объявляешь переменную double cost и булеву переменную isValid = false.
Используем цикл while
	нужно вывести приглашение "Введите стоимость заказа (руб.): ".
	Считать строку ввода и попытаться преобразовать её в double с помощью double.TryParse().
	Если преобразование успешно И cost > 0, установить isValid = true.
	Иначе вывести сообщение об ошибке: "Ошибка! Введите число больше нуля." и повторить ввод.
	Вернуть значение cost.

Переход к решению с помощью подзадач:
 В файле decision
	1) Стоимость заказа
	Имя: InputOrderCost
	Аргументы: отсутствуют
	Тип возвращаемого значения: double

Алгоритм:
1)Объявить переменную cost типа double и булеву переменную isValid = false.
2)Запустить цикл while (!isValid):
	Вывести приглашение: "Введите стоимость заказа (руб.): ".
	Считать строку ввода и попытаться преобразовать её в double с помощью double.TryParse().
	Если преобразование успешно И cost > 0, установить isValid = true.
	Иначе вывести сообщение об ошибке: "Ошибка! Введите число больше нуля." и повторить ввод.
3)Вернуть значение cost.

	2) Расстояние пути доставки
	 Имя InputDistance
	 Тип возвращаемого значения double

Алгоритм:

1) Объявить переменную distance типа double и isValid = false.
2)Запустить цикл while (!isValid):
	 Вывести приглашение: "Введите расстояние доставки (км): ".
	 Считать строку и преобразовать в double через TryParse().
	 Если преобразование успешно И distance > 0, установить isValid = true.
	 Иначе вывести: "Ошибка! Введите число больше нуля."
3)Вернуть значение distance.

	3) Время заказа
	Имя: InputTime
	Аргументы: отсутствуют
	Тип возвращаемого значения: int
Алгоритм:
1)Объявить переменную time типа int и isValid = false.
2)Запустить цикл while (!isValid):
	Вывести приглашение: "Введите время заказа (час): ".
	Считать строку и преобразовать в int через int.TryParse().
	Если преобразование успешно И time >= 0 И time <= 23, установить isValid = true.
	Иначе вывести: "Ошибка! Введите целое число от 0 до 23."
3)Вернуть значение time.

	4)Расчёт стоимости доставки
	Имя: CalculateDeliveryCost
	Аргументы: double orderCost, double distance, int time
	Тип возвращаемого значения: double
Алгоритм:
1)Если orderCost >= 2000, вернуть 0 (бесплатная доставка).
2)Иначе вычислить базовую стоимость:
 	Если distance <= 3, то baseCost = 150.
 	Иначе baseCost = 150 + (distance - 3) * 50.
3)Проверить, является ли время часами пик:
	Если (time >= 12 && time < 14) или (time >= 18 && time < 20), то установить коэффициент наценки surcharge = 1.3.
	Иначе surcharge = 1.0.
4)Вычислить итоговую стоимость доставки: deliveryCost = baseCost * surcharge.
5)Вернуть deliveryCost.

	5)Расчёт итоговой суммы к оплате
	Имя: CalculateTotal
	Аргументы: double orderCost, double deliveryCost
	Тип возвращаемого значения: double
Алгоритм:
1.Вычислить сумму: total = orderCost + deliveryCost.
2.Вернуть значение total.

	6) Вывод результата на экран
	Имя: PrintResult
	Аргументы: double deliveryCost, double total
	Тип возвращаемого значения: void
Алгоритм:
1)Вывести строку: "Стоимость доставки: {deliveryCost} руб." (значения округляются до целых или выводятся как есть, в зависимости от формата, в примере целые).
2)Вывести строку: "Итого к оплате: {total} руб.".
